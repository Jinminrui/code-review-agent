# UI Polish And Chinese Copy

- 日期：2026-06-07
- 目标：在不改页面结构与数据流的前提下，完成导航态、hover、空状态与全站中文文案收口
- 范围：`packages/review-app` 中主工作台、启动页、历史页、设置页及共享壳层的细节 polish

## 1. 范围约束

本轮只做细节收口，不做结构重设计，不新增数据字段，不改 IPC 和状态管理逻辑。

本轮必须覆盖：

1. 全局导航当前态与 hover。
2. 所有面向用户的文案统一改为中文。
3. 主工作台、历史页、设置页的空状态与状态标签更自然。
4. 常见英文状态词，例如 `line-level`、`file-level`、`running` 等，转为中文表达。

## 2. 设计要求

### 2.1 导航态

左侧窄导航不再只是静态文字，应具备：

1. 可点击入口。
2. hover 反馈。
3. 当前页面的明确选中态。

### 2.2 中文文案

所有用户可见标签、标题、分区名、状态名使用中文，保留必要的代码与路径原文。

### 2.3 空状态

空状态文案需要像工作台提示，而不是开发期占位。语气要求直接、克制、可信。

### 2.4 Hover 与微反馈

hover 只做轻量反馈，例如边框加深、轻微上浮或底色变化，不增加夸张动效。

## 3. 影响页面

1. 主工作台：分区名、状态文案、finding 定位状态、diff loading/empty state。
2. 启动页：分区小标题、表单卡说明、按钮状态。
3. 历史页：页头小标题、会话卡小标题、空历史状态。
4. 设置页：页面头区、表单标题与说明。
