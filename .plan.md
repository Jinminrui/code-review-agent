# 修复流式输出问题

## 问题根因

1. **后端**：`unit-completed` 事件只包含 `findingsCount`，不包含实际的 findings 数据
2. **前端**：hook 收到事件后重新调用 `getSession()`，但 `FileSessionStore.getSession()` 在 `completeSession` 被调用前返回空的 findings 和 summary

## 修复方案

### 第一步：修改后端事件 schema

**文件**: `packages/review-backend/src/domain/review-session.ts`

在 `unit-completed` 事件中添加 `findings` 字段：

```typescript
z.object({
  type: z.literal("unit-completed"),
  sessionId: z.string(),
  unitId: z.string(),
  findingsCount: z.number().int().nonnegative(),
  findings: z.array(reviewFindingSchema)  // 新增
})
```

### 第二步：修改后端流式逻辑

**文件**: `packages/review-backend/src/application/stream-review-session.ts`

在 `unit-completed` 事件中包含实际的 findings 数据：

```typescript
const unitCompletedEvent = {
  type: "unit-completed" as const,
  sessionId: session.sessionId,
  unitId: unit.id,
  findingsCount: unitFindings.length,
  findings: unitFindings  // 新增
};
```

### 第三步：修改前端 store

**文件**: `packages/review-app/src/store/review-session-store.ts`

添加增量更新方法 `addFindings`：

```typescript
addFindings(findings: ReviewFinding[]): void;
```

### 第四步：修改前端 hook

**文件**: `packages/review-app/src/hooks/use-review-session-stream.ts`

修改事件处理逻辑，直接使用事件中的 findings 数据：

```typescript
const unsubscribe = ipcClient.subscribeSession(sessionId, (event) => {
  if (event.type === "unit-completed") {
    // 增量更新 findings
    addFindings(event.findings);
  } else if (event.type === "session-finished") {
    // 重新获取完整 session 数据
    ipcClient.getSession(sessionId).then(setSession);
  }
});
```

## 验证方式

1. 运行 `pnpm typecheck` 确保类型正确
2. 运行 `pnpm test` 确保现有测试通过
3. 手动测试：启动审查，观察 findings 是否逐步显示
